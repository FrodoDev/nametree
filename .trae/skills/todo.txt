* 现在选中全部hu节点，一起呼吸的感觉，有阿凡达上那棵圣树的感觉（选中超过一个节点的时候，加强了呼吸感）

功能点
tab 键默认延生树枝 ok
持导出 png ok
调整树干和树根，让它显得更自然 ok
调整树枝角度，以及树枝长度，让树枝更像树冠 ok

树枝拖动，只是改父节点，节点自己的子节点跟随 ok
树干也是可以当成父节点的 ok
树枝的上下位置，可以由拖动位置决定 ok
树枝的拖动逻辑，完全应用到树根，但是树根因为没有上下关系，所以要用虚拟位置表示 ok
根节点和树根默认用黑色 ok
选中节点后，它跟父节点连接的树根或树枝也要呼吸，方便看清楚连接路线 ok
跟 xmind 一样，可以用cmd+单选选中多个节点，也可以拖动鼠标选中 ok
    可以批量拖动，从新赋予父节点
    可以批量修改边框颜色、填充颜色等
    多选逻辑这样做：
        1. 不限制选中的是什么节点，节点之间有什么关系
        2. 可以批量修改选中节点的属性，比如边框颜色、填充颜色等，以及后面会支持的字体修改等
填充颜色：
    边框和填充颜色，在他们后边，保留 9 个历史选中的颜色，这样能让设置颜色效率提高 ok
    历史颜色卡，上下更长的长方形叠放一起。选中的时候有 hover 效果 ok
    加一个边框和填充颜色一起设置的涂色框 ok
备注：
    没有备注的节点，选中节点时，备注栏默认折叠，反之展开 ok
    原本有备注的节点，删除备注后，再切换到节点，备注栏恢复默认折叠 ok
    有备注的节点，有备注的标识 ok
    有备注的节点，鼠标悬浮在上面的时候，浮层现实备注内容 ok
背景：
    给背景添加一个指定的照片  试验后发现不太可行，先搁置
连接：
    节点连接，逻辑上有关联的点，可以通过虚线连接起来 ok
        连接线有两个控制点，能控制曲线走向
        连接线也有备注，备注有浮窗显示
        编辑栏有节点连接和备注的细节展示
        连接线也可以编辑颜色，完全参考节点边框颜色

    支持多棵树，目前只有一颗
    多棵树，可以关联，组成一片树林，比如大学的学科，可以把一个学期的课程表达出来
配色方案：
    添加一些经典配色方案，选定一个方案后，出现这个色系的条形色卡。方案展示用 ipod 专辑列表的老样式，选定色系后的色卡也是。
    选中指定色系后，可以自动上色，系统自动用色系中的颜色，给第一层的节点上色，第一层之后的节点跟第一层的用一样的颜色。允许有节点颜色重复。
格式：
    删除标识

游戏分类大纲：
@title 游戏分类
@topic 游戏类型明细
branches:
    [left] RPG系
        核心是“扮演角色”
        RPG (Role-Playing Game)
            角色扮演游戏
            :: 玩家扮演一个或多个角色，在虚构世界中推进剧情
            代表作
                最终幻想
                仙剑奇侠传
        ARPG (Action RPG)
            动作角色扮演
            :: 在RPG的成长体系上，加入了即时动作元素，非常考验玩家的操作（如闪避、连招）
            代表作
                黑神话：悟空
                原神
        MMORPG(Massively Multiplayer Online RPG)
            大型多人在线角色扮演
            :: 允许成百上千的玩家在同一个虚拟世界中同时在线，极度强调社交、组队和长线养成
            代表作
                魔兽世界
                梦幻西游
    [right] MOBA (Multiplayer Online Battle Arena)
        多人在线战术竞技游戏
        :: 玩家通常被分为两队（如5v5），在特定的地图中各自控制一名拥有独特技能的英雄，通过团队配合、购买装备、推塔来摧毁敌方基地。
        代表作
            英雄联盟
            王者荣耀
    [left] Strategy
        策略类
        :: 强调智力、资源管理、战术规划，而非单纯的操作反应
        SLG（Simulation Game）
            策略/模拟游戏
            :: 包含宏观的战略规划和资源管理
            代表作
                万国觉醒
                万国志
        RTS (Real-Time Strategy)
            即时战略游戏
            :: 所有玩家在同一时间进行资源采集、基地建设、造兵和战斗，极度考验多线操作和宏观决策
            代表作
                星际争霸
                魔兽争霸 3
        SIM (Simulation)
            模拟经营
            :: 节奏自主，通过建造、管理或种田来获得成就感
            代表作
                模拟人生4
                我的世界
        自走棋（Auto Chess）
            “脑力竞技”
            :: 玩家不需要手速，只需要在商店里买棋子、凑羁绊、排阵型，然后看着它们自动打架。核心乐趣在于“排兵布阵”和“赌运气抽卡”
            代表作
                金铲铲之战
                云顶之弈
    [right] Shooter系
        射击类
        :: 以枪械或远程武器战斗为核心，强调瞄准、反应速度和战术配合
        FPS (First-Person Shooter)
            第一人称射击
            :: 玩家以主角的视野进行战斗，代入感极强
            代表作
                CS
                使命召唤
        TPS (Third-Person Shooter)
            第三人称射击
            :: 玩家能看到自己角色的全身，更强调掩体利用和角色动作
            代表作
                绝地求生
                堡垒之夜
        BR (Battle Royale)
            大逃杀
            :: 在大规模生存对战中，玩家需要在不断缩小的安全区内搜集物资，击败其他对手，直到仅剩一人或一队
            代表作
                和平精英
                Apex英雄
        英雄射击（Hero Shooter）
            FPS 和 MOBA 的结合
            :: 它把传统的FPS（第一人称射击）和MOBA（比如《王者荣耀》）缝合在了一起。你不仅要枪法准，还得选不同的英雄，利用他们独特的技能（比如放盾、瞬移、加血）来打战术配合。
            代表作
                守望先锋
                无畏契约
    [left] Action系
        动作游戏
        ACT (Action Game)
            动作游戏
            :: 核心是快节奏的战斗、连招系统，极度考验玩家的反应速度和手眼协调能力
            代表作
                战神
                怪物猎人
        FTG (Fighting Game)
            格斗游戏
            :: 通常在狭小场景内进行1v1对战，强调复杂的招式组合与心理博弈
            代表作
                拳皇
                街头霸王
    Roguelike
        肉鸽类游戏
        :: 特点是“随机生成的地图”和“永久死亡机制”（死后需从头开始或保留部分成长）
        :: 新的肉鸽类游戏，会搭配精妙的三选一机制，在每一轮游戏中给出不同的搭配体验
        代表作
            哈迪斯
    AVG (Adventure Game)
        冒险游戏
        :: 以探索未知、解谜、分析线索和剧情驱动为核心
        代表作
            塞尔达传说
    CAG（Card Game）
        卡牌游戏
        :: 通过收集卡牌、构筑卡组来进行策略对战
        代表作
            炉石传说
            三国杀
    其他
        IO 游戏
            休闲竞技类。上手快，反馈及时
            代表作
                贪吃蛇大作战
                球球大作战
        Party Game
            派对游戏，弱化游戏操作和策略，强化了社交、互动
            代表作
                蛋仔派对
                猛兽派对
                元梦之星
